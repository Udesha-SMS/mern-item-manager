# MERN Item Manager

A simple Item Management System built using the MERN stack.

## Technologies Used

- MongoDB
- Express.js
- React.js
- Node.js

## Project Structure

- `backend/` – Backend API and database connection
- `frontend/` – React frontend application

## How to Run

### Backend

1. Open a terminal in the backend folder.
2. Run `npm install`.
3. Configure the environment variables in your `.env` file.
4. Run `npm run dev`.

### Frontend

1. Open another terminal in the frontend folder.
2. Run `npm install`.
3. Run `npm run dev`.
